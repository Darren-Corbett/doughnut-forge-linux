# 🍩 Doughnut Forge for Linux

Doughnut Forge is a privacy-first, local desktop application designed for secure, encrypted file and identity management. Built entirely on local-first principles, Doughnut Forge operates completely on your own hardware—meaning no cloud dependencies, no external servers, and no recurring subscription models. 

This repository serves as the official public distribution channel for Linux packages.

## Core Features

*   **Absolute Privacy:** Your cryptographic keys and unencrypted data never leave your machine.
*   **Encrypted File Vault:** Manage, store, and organize your files using custom-built encrypted file formats that resist external scraping.
*   **Identity Management:** Securely store and retrieve critical identity credentials behind advanced encryption.
*   **Local-First Architecture:** Operates 100% offline. You own the software and the hardware it runs on.

## Technology Stack

Doughnut Forge is engineered for performance and security using a modern desktop stack:
*   **Core Engine:** Rust & Tauri 
*   **Frontend Interface:** React, TypeScript, Redux Toolkit
*   **Styling & UI:** Tailwind CSS and SVAR UI components
